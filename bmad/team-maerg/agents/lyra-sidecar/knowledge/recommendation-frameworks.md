## How This File Works

1. `*reflect` identifies a gap or growth area from real cycle patterns (accept/reject ratios, drift signals, post-event reflections)
2. `*research [topic]` dives into that area, adds a framework entry here
3. Framework gets applied in Lyra's next cycles — tested against real recommendation outcomes
4. `*reflect` revisits: did it improve accept rate / reduce drift / sharpen taste model?
